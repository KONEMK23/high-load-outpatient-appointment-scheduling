## Speaker script structure

Preserve the existing Slides 1-8 spoken core. Add Chinese translations directly after:

- the delivery-guide instructions;
- each slide's purpose statement;
- each full suggested-speaking paragraph;
- each optional shorter-version instruction.

Evidence lines remain in English because they are source cues rather than spoken text. The Chinese paragraphs are study aids and are not intended to be read aloud during the English presentation.

## Formatting

Preserve the source documents' page setup, heading hierarchy, tables, and existing custom styles. Add a restrained Chinese-translation style that is visually distinct but subordinate to the English text. PowerPoint mapping lines should be easy to scan.
